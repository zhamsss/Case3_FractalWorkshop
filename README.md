
Мастерская фракталов (Fractal Workshop)

Консольное приложение на Python для интерактивной генерации рекурсивных фрактальных узоров и математических кривых с помощью стандартной графической библиотеки turtle. Проект разработан в рамках командного кейса по изучению рекурсивных алгоритмов и модульной архитектуры ПО.

Особенности реализации

• 9 встроенных фракталов: от базовых деревьев до сложных ледяных структур и кривых дракона.
• Интерактивное меню: индивидуальная настройка глубины рекурсии, линейных размеров и углов ветвления для каждого алгоритма.
• Защита от сбоев: валидация пользовательского ввода (try/except) и автоматический контроль лимитов для предотвращения переполнения стека вызовов.
• Оптимизация отрисовки: мгновенный рендеринг через управление буфером экрана (turtle.tracer).

Архитектура проекта

Код структурирован в виде независимого пакета модулей, объединенных единой точкой доступа:
text
FractalWorkshop/
├── main.py                 # Главный исполняемый файл (интерфейс, валидация, цикл работы)
├── fractals/               # Пакет с математическими моделями фракталов
│   ├── __init__.py         # Экспорт публичного интерфейса пакета
│   ├── basic.py            # Двоичное дерево и фрактал «Ветка»

Используйте код с осторожностью.

Реализованные фракталы и параметры

1. Двоичное дерево — классическая крона с регулируемым углом наклона ветвей.
2. Фрактал «Ветка» — ствол с симметричными диагональными отростками и динамическим изменением шага.
3. Кривая Коха — триадическая геометрическая кривая.
4. Снежинка Коха — замкнутый контур из трех кривых Коха с центрированием на холсте.
5. Кривая Минковского — ломаная линия, где каждый сегмент заменяется 8 симметричными элементами.
6. Ледяной фрактал №1 — перпендикулярные симметричные ответвления на основе базового отрезка.
7. Ледяной фрактал №2 — усложненная схема «ледяного» фрактала с углами наклона 115 и 65 градусов.
8. Кривая Леви — фрактальная ломаная, состоящая из сегментов, расположенных под прямым углом друг к другу.
9. Дракон Хартера-Хейтуэя — рекурсивный дракон, строящийся путем последовательного разбиения отрезков под углом 45 градусов.

Системные требования и запуск

Для работы приложения необходим интерпретатор Python версии 3.10 или выше со встроенной поддержкой графического Tcl/Tk (turtle). Дополнительные внешние библиотеки не требуются.

Инструкция по запуску:

1. Склонируйте репозиторий или перейдите в корневую директорию проекта:bash
cd path/to/FractalWorkshop
Используйте код с осторожностью.
2. Запустите главный модуль через консоль:bash
python main.py
Используйте код с осторожностью.
3. Следуйте текстовым подсказкам в терминале: выберите номер фрактала, укажите желаемые параметры и нажмите Enter. Графическое окно откроется автоматически. Для возврата к меню после завершения отрисовки нажмите Enter в консоли.

Лимиты и безопасность вычислений

В модуле main.py жестко прописаны безопасные границы параметров (словарь LIMITS). Это исключает зависание графической системы и появление ошибки RecursionError:
• Глубина для простых фракталов (деревья, Кох, Минковский): до 4–12 уровней.
• Глубина для кривых Леви и Дракона: до 12–13 уровней.
• Линейные размеры ограничены диапазоном от 10 до 500 пикселей для корректного отображения внутри окна 900x750.

Фрактальная мастерская (Case 3)

Проект по программированию (2 курс). Консольная программа на Python с графикой на turtle, которая рисует разные рекурсивные фракталы по параметрам пользователя.

Что внутри (Структура)

text
Case3_FractalWorkshop/
├── main.py                 # Меню, ввод данных, валидация и запуск отрисовки
└── fractals/               # Пакет с алгоритмами
    ├── __init__.py         # Удобный импорт всех функций в одну строчку
    ├── basic.py            # Дерево и Ветка
    ├── koch.py             # Кривая Коха, Снежинка, Минковский
    └── complex.py          # Лед-1, Лед-2, Леви, Дракон
Используйте код с осторожностью.

Список фракталов

1. Двоичное дерево — обычное дерево, можно менять угол веток.
2. Фетка — ствол с отростками.
3. Кривая Коха — базовая ломаная линия.
4. Снежинка Коха — три кривые Коха, собранные в треугольник.
5. Кривая Минковского — каждый отрезок делится на 8 частей.
6. Ледяной фрактал №1 — крестообразные перпендикулярные ветки.
7. Ледяной фрактал №2 — ветки под углами 115 и 65 градусов.
8. Кривая Леви — фрактал из букв «Г».
9. Дракон Хартера-Хейтуэя — рекурсивная кривая дракона.

Как запускать

Нужен Python 3.10+. Никакие библиотеки качать не надо (turtle встроен по умолчанию).
Запуск из корня папки:
bash
python main.py
Используйте код с осторожностью.

Важные фичи

• В main.py зашит словарь LIMITS. Если ввести слишком большую глубину (например, для Дракона > 13), программа выдаст ошибку и попросит ввести заново. Это спасает от RecursionError.
• Включен turtle.tracer(0, 0), поэтому сложные фракталы рисуются мгновенно, а не ползут по полчаса.
• Ввод защищен через try-except от дурака (если вместо цифры ввести буквы, приложение не упадет).
