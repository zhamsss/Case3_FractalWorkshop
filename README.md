# ❄️ Фрактальная мастерская (Кейс №3)

Лабораторный проект по программированию (2 курс НГУ). Консольная программа на Python с графикой на `turtle`, которая строит рекурсивные фракталы и математические кривые по параметрам пользователя.

---

## 🏗️ Архитектура проекта

Код разбит на независимые модули и упакован в пакет:

```text
Case3_FractalWorkshop/
├── main.py                # Точка входа (интерфейс, валидация, логика меню)
├── fractals/              # Пакет с математическими моделями фракталов
│   ├── __init__.py        # Экспорт публичного интерфейса пакета
│   ├── basic.py           # Двоичное дерево, Ветка
│   ├── koch.py            # Линейный Кох, Снежинка, Минковский
│   └── complex.py         # Ледяные узоры, Леви, Хартер-Хейтуэй
└── README.md              # Документация
```

## 🚀 Фичи и защита кода

* **Защита от «дурака»:** Весь пользовательский ввод обернут в `try-except`. Если случайно ввести буквы вместо цифр, приложение не упадет, а попросит повторить ввод.
* **Контроль рекурсии:** В `main.py` зашит словарь `LIMITS`. Он жестко ограничивает максимальную глубину (например, для Дракона — до 13 уровней). Это гарантирует, что программа не поймает `RecursionError` и не зависнет.
* **Быстрый рендеринг:** Программа использует `turtle.tracer(0, 0)`. Фракталы любой сложности отрисовываются мгновенно, а не ползут по экрану часами.

## 💻 Запуск проекта

**Системные требования:** Python 3.10 или выше. Сторонние библиотеки не нужны (`turtle` встроен в Python по умолчанию).

1. Откройте терминал в папке проекта:
   ```bash
   cd Case3_FractalWorkshop
   ```
2. Запустите главный скрипт:
   ```bash
   python main.py
   ```
3. Выберите номер фрактала в консоли, задайте параметры (глубину, длину, углы) и нажмите **Enter**. После отрисовки нажмите **Enter** в консоли, чтобы вернуться в главное меню.
